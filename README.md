# 🏹 MythicalBattle

**MythicalBattle** is a browser-based 3D battle royale prototype focused on movement, shooting and free building.

> ⚠️ **Current version: Alpha**
>
> MythicalBattle is currently in an early Alpha stage. Features may be incomplete, change frequently, or contain bugs.

## 🎮 About

MythicalBattle is a lightweight browser game inspired by the general mechanics of building-focused battle royale games.

The main goal of the project is to create a fun and responsive building system combined with movement and shooting in a simple 3D world.

## ✨ Features

* 🌍 3D open-world environment
* ☁️ Sky and clouds
* ⛰️ Terrain with hills
* 🏃 Player movement
* 🦘 Jumping
* ⚡ Sprinting
* 🎯 Mouse-controlled camera
* 🧱 Free building system
* 🧱 Walls
* ⬜ Floors
* 🔺 Ramps
* 🔄 Building rotation
* 🗑️ Building destruction
* 🔫 Basic weapon system
* 🎯 Shooting
* 🔄 Reloading
* ⚙️ Mouse sensitivity settings
* 💻 Runs directly in a web browser

## 🕹️ Controls

| Key           | Action           |
| ------------- | ---------------- |
| `W A S D`     | Move             |
| `Mouse`       | Look around      |
| `Space`       | Jump             |
| `Shift`       | Sprint           |
| `Left Click`  | Shoot / Build    |
| `Right Click` | Destruction mode |
| `Q`           | Wall             |
| `F`           | Floor            |
| `V`           | Ramp             |
| `R`           | Rotate / Reload  |
| `Esc`         | Settings         |

> Controls may change during the Alpha.

## 🧱 Building System

The building system is one of the main features of MythicalBattle.

Players can quickly switch between different building pieces:

* **Wall**
* **Floor**
* **Ramp**

Building pieces use grid-based placement to make structures align correctly.

A transparent preview shows where the piece will be placed before confirming the build.

## 🔫 Weapon System

The current Alpha includes a basic weapon system.

The weapon currently supports:

* Shooting
* Ammunition
* Reloading
* Basic hit detection

More weapons and gameplay mechanics may be added in future versions.

## ⚙️ Settings

MythicalBattle includes a settings menu where players can adjust their mouse sensitivity.

More settings may be added during development.

## 🚀 Running the Game

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/MythicalBattle.git
```

Open the project folder:

```bash
cd MythicalBattle
```

Then launch `index.html` in a modern browser.

If the browser blocks some features when opening the file directly, use a local server such as VS Code Live Server.
